# HoangMathLib

A [mathlib](https://github.com/leanprover-community/mathlib4)-style staging
library for Lean 4 formalizations in graph theory and combinatorial
reconfiguration, by [Duc A. Hoang](https://hoanganhduc.github.io/).

- Lemmas destined for mathlib file `Mathlib/A/B/C.lean` live at
  `HoangMathLib/Mathlib/A/B/C.lean`, in mathlib's namespaces, following the
  community satellite-library convention.
- Research code in progress lives under `HoangMathLib/Reconfig/` and friends.
- The [upstreaming dashboard]({{ site.baseurl }}/upstreaming) tracks which
  files are ready to move into mathlib.

Source: [github.com/hoanganhduc/HoangMathLib](https://github.com/hoanganhduc/HoangMathLib)
